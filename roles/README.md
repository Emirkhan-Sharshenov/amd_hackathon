# Мандаты ролей (generic)

Правило хакатона: **мандаты только generic**. Нарушение — быстрейший путь к дисквалификации.

Мандат = постоянная инструкция роли: чем владеет, как передаёт работу, что отклоняет.
Мандат **не содержит**: имён полей, URL, статус-кодов, ID элементов, названий сущностей, бизнес-правил конкретной задачи.
Всё это приходит из спецификации задачи во время работы.

Проверка: отдай мандат команде, которая строит что-то совсем другое. Если он всё ещё имеет смысл — ок.

| Роль | Пишет код? | Суть |
|---|---|---|
| [architect](architect.md) | нет | Режет работу на срезы, ведёт чек-лист контракта, выносит вердикт |
| [builder](builder.md) | **да** | Единственный, кто меняет продакшен-код |
| [spec-warden](spec-warden.md) | нет | Буквальное соответствие спеке |
| [verifier](verifier.md) | тесты | Прогон тестов, регрессии, граничные случаи |

Мандаты написаны на английском — так их надёжнее понимают модели. Черновики: доработать после знакомства с BAND Desktop на kickoff.
